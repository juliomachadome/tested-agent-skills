# Reuse and attribution

You may use, copy, adapt and redistribute Tested Agent Skills, including for commercial purposes, under [CC BY-SA 4.0](LICENSE).

If you copy or adapt material from this repository and share it publicly, give credit in a `README`, `NOTICE` file, product credits, legal page or equivalent documentation. A public README is the preferred location when one exists.

## Quick rule for people and agents

- **Permission:** commercial and personal use, copying and adaptation are allowed.
- **When credit is needed:** when shared material copies or adapts this repository.
- **What to include:** `Tested Agent Skills`, `Júlio Machado`, the repository link, `CC BY-SA 4.0`, and a short description of changes.
- **Where:** public project → `README`; commercial app/SaaS → `NOTICE`, legal page or product credits; internal system → technical documentation or `NOTICE`.
- **ShareAlike:** publicly shared adaptations remain CC BY-SA 4.0 or use a compatible license.

### Agent-ready instruction

```text
You may use Tested Agent Skills commercially and may adapt them.
If the deliverable copies or shares adapted repository material, add attribution:
"Uses or adapts Tested Agent Skills by Júlio Machado —
https://github.com/juliomachadome/tested-agent-skills — CC BY-SA 4.0."
State the changes made. Put this in the README for a public project,
or in NOTICE, legal credits, product credits or internal technical docs
for a commercial or internal product. Keep shared adaptations under
CC BY-SA 4.0 or a compatible license.
```

## Choose the place that fits the use

| Use | Good place for credit |
| --- | --- |
| Personal or open-source project | `README.md` under `Credits` or `Acknowledgements` |
| Library, plugin, template or starter kit | Package README and `NOTICE` file |
| Commercial app or closed-source product | Legal/third-party-notices page, product credits or "About" screen |
| SaaS or internal company system | Internal technical documentation, `NOTICE` file or legal page |
| Client or consulting delivery | Handover document, repository README or third-party notices supplied to the client |
| Course, article, video or presentation | Credits, description or resources page |
| Agent, assistant or automation | Its project README, agent documentation or a `NOTICE` file distributed with it |

## Commercial app, SaaS or internal system

Place this in a `NOTICE` file, legal page, product credits, "About" screen or internal technical documentation. This works for a paid app, a closed-source SaaS or a company-only system:

```text
Third-party notices

This product uses or adapts Tested Agent Skills
by Júlio Machado (@juliomachadome):
https://github.com/juliomachadome/tested-agent-skills

Licensed under CC BY-SA 4.0.
Changes: <brief description of the changes, or "none">.
```

## Client work, courses and content

For client work, put the same notice in the delivery README, handover document or third-party-notices list. For a course, article, video or presentation, put the project link and license in its credits, description or resources page.

Use **"uses"** when repository material is included unchanged. Use **"adapts"** when it has been modified.

## Agents and AI tools

Agents and AI tools may load and use these skills under the same license. If an agent configuration, prompt pack, plugin or automation copies or publicly shares adapted repository material, include the applicable attribution in its README, documentation or `NOTICE` file.

## What ShareAlike means in practice

Publicly shared adaptations of this repository's material must remain under CC BY-SA 4.0 or a compatible license. That condition applies to the adapted material, not automatically to every unrelated part of a commercial product that uses a skill. This notice cannot decide difficult legal boundaries; the [license text](LICENSE) controls.

This notice explains the intended attribution practice and is not legal advice.
