# Bibliography: software-security

Checked 18/11/2026. Status: **V** = identity (title, authors as far as the catalogue shows, year) matched to the ISBN in OpenLibrary (`https://openlibrary.org/isbn/<isbn>.json`, authors via the works and authors endpoints) this pass; **P** = official page opened and the relevant text read this pass (a note says when only the first part of a long page, a landing page or a locale variant was read); **S** = page exists, text not read this pass (needs browser pass); **U** = not verified. Nothing is quoted; ideas are restated. In `SKILL.md` and the topic references the codes W1 to W55 point to `sources.md` (earlier read pass, dates there); B-numbers below are used in `diagnosis-playbook.md`, `playbooks.md` and `mobile-security.md`.

## Books

2. Shostack, A. *Threat Modeling: Designing for Security*. Wiley, 2014. ISBN 978-1118809990. **V**. BOOK. Supports: `playbooks.md` 1 (data flow, STRIDE).
3. Zalewski, M. *The Tangled Web: A Guide to Securing Modern Web Applications*. No Starch Press, 2011. ISBN 978-1593273880. **V** (OpenLibrary edition record has no author; the work record links to Michal Zalewski). BOOK, dated: browser details have changed, use for the same-origin and content-sniffing mental model only.
4. Stuttard, D., Pinto, M. *The Web Application Hacker's Handbook*, 2nd ed. Wiley, 2011. ISBN 978-1118026472. **V** (Stuttard via authors endpoint; Pinto per the catalogue statement). BOOK, dated. Supports: attacker method (`SKILL.md` Method).
5. Anderson, R. *Security Engineering*, 3rd ed. Wiley, 2020 (catalogue year 2021). ISBN 978-1119642787. **V**. BOOK. Supports: proportion, incentives, failure of controls.
6. Janca, T. *Alice and Bob Learn Application Security*. Wiley, 2020. ISBN 978-1119687351. **V**. PRACTITIONER. Supports: secure SDLC routine for small teams.

## Standards, OWASP and web platform

The page shows no release date.
8. OWASP Foundation. *Application Security Verification Standard (ASVS) 5.0.0*. May 2025. https://github.com/OWASP/ASVS . **P** 18/11/2026: latest stable is 5.0.0 (released at Global AppSec EU Barcelona 2025); the v5.0.0 `5.0/en` tree lists chapters V1 Encoding and Sanitization through V17 WebRTC. 10. OWASP Foundation. *Web Security Testing Guide (WSTG)*. https://owasp.org/www-project-web-security-testing-guide/ . **P** 18/11/2026: stable v4.2, v5.0 in development; business-logic test pages (BUSL) read by index only.

16. OWASP Foundation. *File Upload Cheat Sheet*. https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html . **P** 18/11/2026: extension allowlist, generated names, storage, size, path check.

## Database, payments, CI and further primary sources
