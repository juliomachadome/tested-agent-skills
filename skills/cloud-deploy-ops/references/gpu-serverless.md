# Serverless GPU (RunPod as the example)

Format: **rule** · why · source `[n]` (see `BIBLIOGRAPHY.md`) · example. Checked 15/11/2026. GPU hourly rates change often: take them from the provider's pricing page on the day, not from this file.

1. **Minimum (active) workers = 0 is the only zero-idle-cost setting.** Active workers run 24/7 and bill continuously `[43]`. Console defaults `[44]`: max workers 3, active 0, idle timeout 5 s (the REST v2 default is 10 s), execution timeout 600 s (REST v2 300 s), job TTL 24 h, FlashBoot on in the console and off by default in REST v2. Check which API created the endpoint.
2. **What is billed** `[43]`: per second from worker start to full stop: cold start (model load), execution and the idle timeout after the last job. A scaled-down worker costs nothing; pulling the image and downloading cached models while scaled down are not billed. Storage: container disk about USD 0.10/GB-month; network volume USD 0.07/GB-month under 1 TB.
3. **Cost per job = cold start + execution + idle,** times the per-second rate; estimate the month from jobs per day and how often the worker is cold, not from the hourly price alone (worked example in `diagnosis-playbook.md` section 5).
4. **Scaling type matters** `[44]`: queue delay adds workers when requests wait more than a threshold (default 4 s); request count scales on pending plus active work divided by a scaler value. Both multiply spend under a burst, bounded by max workers.
5. **`/run` and `/runsync` have no idempotency key** `[45]`. A timeout or 5xx on submit may have created the job and a resubmit is billed separately. Track by job id with `/status`; use `/retry` (same id and input) only for failed or timed-out jobs; resubmit only on an explicit 429. If a submit failed without an id, record "may have been billed" and check the usage panel.
6. **Results are short-lived** `[45]`: async results about 30 minutes after completion, sync results about 1 minute (the page also says up to 5). Persist immediately. Set `executionTimeout` and `ttl` per job type; TTL counts queue plus execution.
7. **The spend limit is a cap, not an alert:** default USD 80 per hour across all resources, raisable through support `[43]`. Prepaid balance is the real ceiling. After every test or deploy read current spend per hour and worker count from the API, and say "off" only when both are zero. A low-balance alert was not found in the docs.
8. **Images by tag or digest, never `latest`; no secrets in the image** (tokens for model downloads go in the endpoint's environment) `[47]`.
9. **Reference prices on the day** `[46]`: pod rates USD 1.19/h (A100 PCIe community) to USD 2.09/h (secure); H100 SXM USD 2.69 to 4.39/h. These are pod rates, not serverless per-second rates, which were not extracted from the page.
10. **Personal data sent to a GPU provider is a processor relationship** and often an international transfer: see the privacy law of the data subject's country (official regulator pages) before sending real recordings or documents.
