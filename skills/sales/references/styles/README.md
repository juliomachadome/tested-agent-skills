# Sales styles: how to pick one

A style is how you run conversations; method detail stays in `../methods.md` and `../playbooks.md`. Project rules and the buyer's own habits win over this table. Styles combine: a founder-led enterprise deal can use consultative questions inside a MEDDICC plan.

| Deal size | Cycle | Buyer | Channel | Style file |
|---|---|---|---|---|
| Small, card-ready | Days | Individual or small team | Inbound, product trial | `self-serve-plg-assist.md` |
| Small to mid, first customers | Weeks | Founder-reachable | Direct, warm network | `founder-led.md` |
| Mid to large | 1-6 months | One or few stakeholders, known problem | Outbound or inbound | `consultative-spin.md` |
| Mid to large, status quo is comfortable | 2-6 months | Does not see the problem | Outbound | `challenger.md` |
| Large | 3-12 months | Buying group, procurement | Direct, partners | `solution-meddicc-enterprise.md` |
| Any, price is the argument | Any | Compares with a cheaper option | Any | `value-selling.md` |
| Mid to high consumer ticket | Days | Individual who applied | Call after application | `high-ticket-closer.md` |
| Public contract | Months | Authority and evaluators | Official notice | `b2g-tender.md` |
| Cross-border or mixed-culture | Any | Different communication norms | Any | `cultural-adaptation.md` |

Every file has: when to use, core moves, a sample talk track, what to avoid, an evidence tag (C consensus or law, M serious single or old, F practitioner) and the source. Ethics limits in SKILL.md section 8 apply to all styles.
